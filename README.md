# 🍄 蘑菇卡丁车 · 岛主出品 (Mushroom Kart Club)

> 基于 Three.js 与 Node.js 打造的 3D 卡丁车多人实时在线对战与求生割草竞技游戏。

---

## ✨ 游戏核心特色

1. **三大玩法模式**：
   - 🏎️ **卡丁车大奖赛**：支持单人对战 5 位 AI 电脑车手，或通过 6 位房间码与好友多人实时同屏竞速（支持漂移集气、小喷加速与 8 种特色道具互动）。
   - 🧟 **蘑菇街求生**：类吸血鬼幸存者的 3D 街区割草射击生存模式，支持 1~4 人组队开黑，拥有丰富的武器切换、波次怪物与金币结算。
   - 🅿️ **蘑菇街抢车位**：20 款赛车离线放置收益经营玩法。
2. **20 款程序化 3D 赛车 & 4 大主题赛道**：
   - ChatGPT 灵感舱、Claude 星芒号、豆包气泡号、Gemini 双子星等 20 款赛车。
   - 碧姬皇家花园、蘑菇森林环线、酷霸王山谷、风火轮公园。
3. **低延迟网络架构**：
   - 权威服务端物理模拟（20Hz/30Hz 帧同步）。
   - WebRTC P2P 毫秒级直连信令中继支持。
   - 跨端畅玩：电脑键盘、手机触屏均自适应支持。

---

## 🚀 本地快速启动

```bash
# 启动游戏与联机服务（默认端口 7788）
npm start
```

* 本地访问：[http://localhost:7788/](http://localhost:7788/)
* 同局域网手机/平板开黑：`http://<局域网IP>:7788/`

---

## 🌐 生产环境一键部署

本工程支持一键部署至各类云平台（Render、Zeabur、Railway、Koyeb 或 Docker）：

* **Render / Zeabur**: 直接关联此 GitHub 仓库，选择 Node 运行时，启动命令填 `npm start` 即可。
* **Docker 部署**：
  ```bash
  docker build -t daozhu-kart .
  docker run -d -p 7788:7788 daozhu-kart
  ```
